## 本期要点

窗口内（10-19 09:00 ～ 10-20 09:00，周一）最重的变化来自企业侧智能体治理：微软在同一天用两篇官方博客把「Agent 是最新内部人」写成产品路线——Entra Agent ID 扩展身份类型以覆盖本地 Agent 与此前未被发现的 Agent，Microsoft 365 E7 与 Project Perception 新增按 Agent 评估风险并阻止其做出变更的能力；同窗口内 GitHub Copilot 的六款模型退役于 10-19 正式生效，这是台账 10-15 记录的「11-16 批次」之前的一批。发布侧有两条实打实的：蚂蚁 inclusionAI 把 Ming-3.0 五款语音模型（0.5B～126B，MIT）全部开源，补上了开源表演级 TTS 之外「可自托管的音频理解 + 上下文 ASR」这一环；AI 芯片初创 Tenstorrent 完成 15 亿美元 E 轮、估值 62 亿美元，且明确在与英特尔、高通谈过收购后选择独立发展。科研与认知面，本期靠一条【补录】补上：Anthropic 前线红队 10-16 披露 Claude 内部研究模型在半小时内还原出 NIST 五条椭圆曲线公开种子的生成方式（lrand48 + 1997～1998 年的 Unix 时间戳），已在 10-17～19 经密码学者复现并在 10-19 于中文与加密媒体二次铺开——这是本期唯一一条「模型能力直接解决真实科学悬案」的样本。世界模型方向本期密度很高：南京国内首个物理 AI 与世界模型大会 10-19 开幕、生命世界模型平台 WHIRLPO 落地、加上上一轮的 EdenLive，国内正在把「世界模型」从论文推向产业口径。

## 1. 微软把 AI 智能体当「内部人威胁」：Entra Agent ID 新身份类型 + E7/Project Perception 风险阻断

**发生了什么**：微软 10 月 19 日同日发布《Securing the agentic insider》（官方博客）与《Agents are your newest insiders. Security must move at their speed.》（安全博客），宣布扩展 Microsoft Entra Agent ID 的身份类型以覆盖更多智能体形态，包括本地运行的 Agent 与此前并不知晓存在的 Agent；Microsoft 365 E7 与 Project Perception（7 月推出的多智能体安全系统，内含红队/蓝队/绿队智能体）新增能力可对每个智能体评估风险并阻止其做出变更，同时把零信任延伸到 Agent 流量；同批 Copilot Studio 智能体以独立身份运行的能力进入预览。背景是 Entra Agent ID 已于 2026-05-01 随 Agent 365 正式可用（Agent 365 单独定价每用户每月 15 美元，并包含在 Microsoft 365 E7 中）。

**为什么值得关注**：台账里 Agent 越权已连续三期出现（OpenAI 19 起失准报告 10-15、CERT-In 国家级通告 10-15、腾讯承认智能体探测高德 10-16），微软这次给的答案不是「再套一层沙箱」，而是把 Agent 纳入与企业员工同构的身份—条件访问—生命周期治理体系（可被条件访问策略阻断、可被发起人生命周期工作流回收）。对在国内做企业 Agent 落地的人，这是目前最完整的参考实现；与同窗口 ServiceNow AI Passport 构成本期「Agent 身份层」的正面双样本。

## 2. 蚂蚁 inclusionAI 开源 Ming-3.0：五款语音模型覆盖 TTS/音频理解/ASR，MIT 许可

**发生了什么**：蚂蚁集团 inclusionAI（Ant Ling 团队）于 10 月 19 日开源 Ming-3.0 系列五款模型，横跨三个家族：Ming-3.0-tts-0.5B（稠密，主打声音设计与副语言线索控制）、Ming-3.0-tts-tiny（7.9B 总参/1.3B 激活）、Ming-3.0-audio-flash（126B 总参/6.5B 激活的 MoE 音频理解模型）、Ming-3.0-audio-tiny（9.3B/2.7B）与 Ming-3.0-asr-tiny（8.6B/2B，支持方言与口音、可用热词与上文对话做上下文 ASR）。许可为 MIT，权重在 Hugging Face 与 ModelScope，vLLM（vLLM-Omni）与 SGLang 提供 day-0 支持。据其自述与第三方榜单，tts-0.5B 在「受控语音」开源权重项排第一（约 1069 Elo）、发音鲁棒性 93.2%，asr-tiny 在四类 ASR 任务平均错误率 4.41%、覆盖 15 组方言集；Artificial Analysis 开源权重 TTS 榜上 Ming-3.0-tts 以约 1188 Elo 位列第三，前两位是 Fish Audio Drama 3 Preview（1247）与 Breeze TTS 2（1222）——注意 1069 与 1188 分属不同评测分项，不可直接比较。另需留意：有第三方指出 tts-0.5B 的权重早在 9 月 24 日即已上架 HF、10 月 19 日释出的是推理代码，官方未发公告。

**为什么值得关注**：这是本期 AI Audio 唯一的新发布，且一次补齐三类能力——上周 Fish Audio Drama 3（10-13～14）解决「开源表演级 TTS」，本条解决「开源大参数音频理解 + 可带热词/上文的 ASR」，而 MIT 许可 + vLLM/SGLang day-0 意味着可直接进生产链路。对做语音 Agent、字幕校对与方言语音的人，126B 音频理解模型开源是本期最实质的一步。
来源：[蚂蚁开源动态（Ant Ling X）](https://x.com/AntLingAGI/status/2112210811997540475)、[vLLM day-0 支持](https://x.com/vllm_project/status/2112220256941085002)、[inclusionAI HF 集合](https://huggingface.co/inclusionAI/collections)、[AICoder 规格梳理](https://aicoder.com/news/news-20261019-ant-ling-ming-3-0-open-source-speech-models)、[Artificial Analysis TTS 榜](https://artificialanalysis.ai/text-to-speech/leaderboard/provider-voice)

## 4.【补录 10-16，10-17～19 持续发酵】Claude 还原 NIST 五条椭圆曲线种子的生成方式

**发生了什么**：Anthropic 前线红队（Frontier Red Team）10 月 16 日发布披露：一名员工把困扰密码学界二十多年的问题交给 Claude 内部研究模型、且未提供关键线索，模型在不到半小时内还原出 NIST P-192、P-224、P-256、P-384、P-521 五条公开曲线种子的生成方式——它们是 C 库伪随机函数 lrand48 的输出，种子取自 1997～1998 年间的六个 Unix 时间戳；这些数字由 NSA 于 2000 年提供给 NIST，但「如何选出」从未公开。结论意味着曲线种子并不来自官方暗示过的「无可指责的随机过程」，但 ECDSA 本身并未被破解，多个独立实现已可在数秒内复现。量子位 10 月 17 日、Technology.org 与加密媒体 10 月 19 日继续铺开，多位密码学者（含 Valsorda）确认复现成立。

**为什么值得关注**：这是台账里第一条「前沿模型解出真实世界长期悬案」并获同行独立验证的案例，性质不同于跑分（对比 Sakana 的 LLM 同行评审 10-10、AgentGarten 10-11 仍停在评测框架层）。对 AI coding 与安全方向的实际含义是：具备长链搜索与工具编排能力的模型可以承担研究级任务，而「标准里的神秘常数」这类审计问题从此有了自动化路径。
来源：[Anthropic 前线红队披露（10-16）](https://www.anthropic.com/news)、[Unite.AI](https://www.unite.ai/anthropic-says-claude-traced-nist-ecdsa-curve-seeds-to-a-1990s-rng/)、[技术梳理](https://cellcog.ai/blog/claude-ecdsa-curve-seeds/)、[10-19 二次报道](https://www.technology.org/2026/10/19/claude-nist-p256-curve-seeds-lrand48-timestamp/)、[量子位](https://www.qbitai.com/2026/10/503910.html)

方向标签：泛AI(科研)/Agent(安全)｜日期：2026-10-16（10-17～19 发酵）【补录】
