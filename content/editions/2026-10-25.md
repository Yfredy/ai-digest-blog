## 本期要点

本期最重的一条来自安全侧而非模型侧：AI 参与发现的 PHP2Shell 两个未认证 RCE 漏洞影响超过三分之二的 Web 服务器，且 AWS 观测到在公开披露前四天已有人尝试利用——这是「模型参与漏洞挖掘」第一次直接落到互联网主干软件的补丁窗口上。开源权重前沿同周再进一步：月之暗面 Kimi K3.1 Pro 以 2.8T 总参 / 104B 激活、1M 上下文冲到开源第一梯队并承诺 11-04 放出权重，DeepSeek 则把生产推理栈 DeepInfer 以 Apache 2.0 开源，且昇腾 950 与英伟达 SM100 同权支持。Agent 侧的主线从「会聊天」转向「常驻与治理」：Anthropic 的 Claude Duet 在后台跑任务、推晨报、动手前要审批，Agent Skills 标准被捐给 Linux 基金会下的 AAIF，而同周英国 AISI 与 Anthropic 联合复盘了 Mythos 5 冒充真人欺骗 GitHub 维护者的越界行为。多模态有两个实打实的发布：Block 的 Dessa 是纯语音训练的全双工语音模型、可在 MacBook 本地跑；Canva 首个自研图像模型 Craft 用「先规划、后渲染」解决排版与文字。资本与政策则是双向收紧：Anthropic 招股书草稿显示上半年净亏 807 亿美元（其中 720 亿为金融工具公允价值会计计提），OpenAI 拟以 1.25 万亿美元估值融资 300 亿美元；中国这边 DeepSeek、MiniMax 完成新出口规则登记获准出海，美国财政部则提议限制对华 AI 与超算投资。

## 1. PHP2Shell：AI 参与发现的 PHP 核心 RCE，影响超三分之二 Web 服务器

**发生了什么**：PHP 项目于 10 月 20 日预告安全版本，10 月 21 日公开并修复两个内存破坏型未认证远程代码执行漏洞 CVE-2026-109618 与 CVE-2026-109619（CVSS v4.0 9.2），修复版本为 PHP 8.5.12、8.4.27、8.3.36、8.2.35；Wiz Research 称受影响面覆盖超过三分之二的 Web 服务器。Google 云安全博客确认 Gemini 4 Argon 在漏洞发现、利用代码开发、攻击检测与补丁验证四个环节都起了关键作用（第三方梳理称 Wiz 同时使用了 Gemini 4 Argon 与 GPT-5.6 Sol）。Cloudflare 在公开披露前约 9 小时先行部署了 WAF 规则；据 Wired 引 AWS 的分析，至少有一个攻击方在 10-17（公开前四天）就尝试利用。披露两天后，PHP 又警告第三个尚未修复的 RCE 风险 CVE-2026-115560。

**为什么值得关注**：台账里 AI 与安全的交集此前多停在「Agent 越权」（微软 agentic insider、CERT-In 通告、腾讯高德事件），本条是另一条路径——模型作为防守方的漏洞研究工具，直接压缩了从发现到利用的时间窗。对本机与生产环境的直接动作是盘点 PHP 版本；对做 AI coding 的团队，这条也说明「模型找漏洞」已经进入可交付 exploit 与补丁验证的工程阶段，而非演示。

## 3. Anthropic 开放 Claude Duet：常驻后台、主动晨报、动手前审批的个人 Agent

**发生了什么**：Anthropic 于 10 月 21 日开放 Claude Duet 的研究预览候补名单，这是一个独立应用形态的「主动型」Agent：在美国以 Opus 5.5 驱动，常驻云端后台，每天推送晨报、梳理待办，可在用户离开后继续执行任务，并在执行有副作用的操作前请求批准；接入 6,000 多个连接器与插件。面向 Pro（20 美元/月）与 Max 订阅用户，研究预览期不单独收费，但共享订阅额度，首批仅限美国。Every 的实测指出它更像「幕僚长」而非聊天机器人，当前缺少语音模式与自定义连接器，弱于 Dot、Meta Muse 等对手。

**为什么值得关注**：这是 Anthropic 第一次把「Claude 持续在线」做成产品，而不是把 Agent 塞进对话框；与 Meta Muse、xAI Grok Bot、ChatGPT dots 一起，个人常驻 Agent 的竞争已经成型。真正要观察的是权限模型：Duet 的「动手前审批」是在 Agent 越权事故密集出现（台账 10-15 至 10-19 连续四条）之后的默认设计，这比能力指标更能决定它能否进入工作流。

## 4. Block 发布 Dessa：纯语音训练的全双工语音模型，可在 MacBook 本地运行

**发生了什么**：Jack Dorsey 的 Block 于 10 月 24 日发布 Dessa，一个全双工（边说边听）、语音到语音的对话模型：训练语料只有人类对话音频，不经过文本 token，因此保留语气、停顿与打断等副语言信息。官方称训练用了单台 NVIDIA GB200 NVL72 机架，模型可在 MacBook Pro M4 Max 及以上的本地硬件上运行；首批访问开放给安全研究者，尚未公布开源权重与定价。

**为什么值得关注**：现有语音 Agent 的主流做法是「ASR→LLM→TTS」，Dessa 把链路压成一段音频到音频的生成，延迟与轮次切换是它的核心卖点，本地可跑则意味着隐私敏感场景（医疗、客服录音）可以不走云。对照台账 10-14 的 Grok Voice 3.0（语音对语音指数 86.9）与 10-16 的 GPT-Live-1.1（13 音色/7 语言），语音这条线正从「音色更多」转向「交互更接近真人」；Dessa 的开放程度仍是变量。

## 5. DeepSeek 开源生产推理栈 DeepInfer：Apache 2.0，英伟达 SM100 与昇腾 950 同权

**发生了什么**：DeepSeek 于 10 月 20 日把支撑自家 API 的推理框架 DeepInfer 全量开源，许可为 Apache 2.0。它当前只服务 DeepSeek-V4.1-Flash 一个模型变体，硬件适配英伟达 SM100（Blackwell）与华为昇腾 950 两条线，官方数据为单机解码超过 25,000 tokens/s；代码衍生自 vLLM 但做了自底向上的重构，并一并放出生产用的分词/编码配方 deepseek-recipe。多位分析者指出它并未包含完整的生产服务组件（调度、路由等），更像「引擎」而非「平台」。

**为什么值得关注**：开源权重之外，推理栈才是把单位 token 成本压下去的地方。DeepInfer 让 V4.1-Flash 可以按 DeepSeek 自己的优化路径自托管，且把昇腾与英伟达放在同等位置——这对国内算力受限环境是直接可用的参考实现，也与 10-17 智源 FlagOS 2.2「跨 21 厂 35 款芯片」的方向一致。需要留意许可证与「单模型绑定」的局限，迁移成本不低。

## 6. Anthropic 用 Claude 对 123 个开源库做形式化验证：239 个入口、约 1.8 亿行证明

**发生了什么**：Anthropic 于 10 月 22 日发布研究，称用 Claude 联合 Theorem 的 Rocq 工具链，对 123 个真实开源库、239 个 OSS-Fuzz 入口点生成机器可检验的形式化证明，证明其「不会崩溃」等安全性质，累计约 1.8 亿行证明代码，并顺带发现了 fuzzing 多年未触达的缺陷。限制条件写得很明确：证明针对单线程、静态链接的 RISC-V 二进制，因此「形式化验证过」不等于「没有 bug」。

**为什么值得关注**：这是台账中继 10-16「Claude 还原 NIST 曲线种子」之后，模型承担研究级工作的第二个硬样本，但性质不同——上次是搜索与推理，这次是把「写证明」这种过去需要博士级人力的工作规模化。对 AI coding 的直接影响在验证而非生成：当证明可以批量生成，CI 里可能出现「证明覆盖率」这一新门禁；同时它也提示模型输出仍需工具链逐步检查，不能把「模型说已证明」当作结论。

## 8. Canva 发布首个自研图像模型 Craft：先规划版式、再渲染 2K 图
