## 发生了什么

论文《AgentGarten: Code Worlds for Evolving Agents》（arXiv 2610.12374）登上 Hugging Face Papers 近期热榜。框架把模拟器/游戏引擎与「共享实时神经渲染器」耦合，让多个 Agent 在持久、可交互的代码世界里通过视觉观测实时行动，并把每轮经验蒸馏沉淀回世界本身，形成可复用的集体练习场；作者开放了渲染器。

## 为什么值得关注

当前 Agent 训练普遍困在「一次性沙箱 + 无状态试错」，AgentGarten 把练习环境变成共享、持续进化的世界，是 Agent 与世界模型路线合流的代表样本，也呼应了本期窗口外 Grok Imagine 等「世界模型化」趋势。
