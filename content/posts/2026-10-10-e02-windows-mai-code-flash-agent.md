## 发生了什么

微软 10 月 7 日 Windows/Surface 发布会后，10 月 8-9 日多家媒体与官方博文持续放出细节：微软 AI 开发了本地版 MAI Code 1.1 Flash——面向编码优化的 MoE 模型，总参数 137B、激活约 6.8B，可在 Surface/NVIDIA 新硬件上本机运行；Windows 11 引入 Microsoft Execution Containers 作为 Agent 的系统级沙箱运行容器并已 GA，与 NVIDIA 合作扩展本地 AI 处理、混合模型路由和 Agent 安全控制；同期发布 Surface Laptop Ultra 等 AI 优先硬件。

## 为什么值得关注

这是「AIOS」方向本期最重的事件——操作系统厂商首次把大参数编码模型、Agent 沙箱、硬件路由整合进 Windows 主线更新，端侧 Agent 运行时从概念走向亿级设备。
