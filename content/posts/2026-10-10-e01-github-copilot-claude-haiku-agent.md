## 发生了什么

GitHub 于 10 月 9 日发布 Copilot 周度更新汇总：Claude Haiku 5.5（Anthropic 10 月 7 日发布的模型）正式上架 Copilot Pro/Max 档位，可在 VS Code 等环境选用；Copilot CLI 的本地沙箱（real-time sandboxing）面向全部用户 GA，Agent 的文件系统与网络访问权限可在本机细粒度控制；Copilot 应用支持 GitHub 账号与许可证账号分离，方便跨组织/多环境使用。

## 为什么值得关注

主流 coding agent 的「本地沙箱 + 权限控制」从实验特性转正，意味着多模型接入与安全执行环境正在成为 IDE/CLI 工具的标配，对企业放开 agent 自动化写代码是关键一步。
